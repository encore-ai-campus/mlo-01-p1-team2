## 2. 프로젝트 개요

### 프로젝트 명

자동차·FAQ 데이터 수집 및 적재 파이프라인

### 프로젝트 소개

자동차 등록 데이터, 중고차 데이터, 기업 FAQ 데이터를 API와 웹 페이지에서 수집하고 정제하여 JSON, CSV 및 데이터베이스에 저장하는 프로젝트입니다.

### 프로젝트 필요성(배경)

데이터마다 제공 방식과 형식이 달라 수작업으로 수집하고 정리하기 어렵습니다. 반복 가능한 수집 과정과 데이터 검증 절차를 구축하여 관리하기 쉽게 만드는 것을 목표로 합니다.

### 프로젝트 목표

- 자동차 및 FAQ 데이터 자동 수집
- JSON과 CSV 형식으로 데이터 저장
- 중첩 데이터 평탄화 및 형식 변환
- 중복 데이터와 오류 데이터 검증
- MySQL과 MongoDB 적재 기반 마련
- 재실행과 장애 상황을 고려한 수집 구조 구현

## 5. 요구사항 명세서

- 승인된 출처에서 자동차 및 FAQ 데이터를 수집합니다.
- 수집 데이터를 JSON과 CSV 형식으로 저장합니다.
- 중첩된 JSON 데이터를 CSV에 적합한 형태로 변환합니다.
- 필수값 누락과 중복 데이터를 검증합니다.
- 동일한 데이터를 다시 실행해도 중복 저장되지 않도록 합니다.
- 오류 발생 시 재시도하고 실행 결과를 기록합니다.
- API 키와 데이터베이스 비밀번호를 코드에 직접 저장하지 않습니다.

## 7. 주요 프로시저

1. API 또는 웹 페이지에 요청하여 데이터를 수집합니다.
2. 응답 형식과 필수 항목을 검증합니다.
3. HTML 태그와 불필요한 값을 정리합니다.
4. 중복 여부를 확인한 후 JSON 또는 CSV 파일로 저장합니다.
5. 저장된 데이터를 MySQL 또는 MongoDB에 적재합니다.
6. 실행 결과와 오류 내용을 로그로 기록합니다.
7. 전체 과정을 자동화하여 정해진 주기에 따라 실행합니다.
